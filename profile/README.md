A web studio in Thimphu, Bhutan. We design, build and look after websites for Bhutanese businesses: fast on every phone, easy for you to update, priced in Nu. and quoted in writing.

**What we do:** UI/UX design · graphic design · branding · WordPress websites · AI-assistant websites · hosting · domains · migration

**How we build:** static sites with Astro, content you edit yourself in Sanity, hosted on Cloudflare Pages. Pages load fast on the phones people in Bhutan actually use, and updates install themselves.

Client work stays private. Case studies are on [nine75.com](https://nine75.com).
